## 🎮 About the Game

Capy Castaway is a cozy narrative exploration adventure developed by Kitten Cup Studio and published by Big Blue Sky Games. It released on August 6, 2026, for Windows and macOS. Players guide a capybara pup and a clever crow across a mysterious island, solve light puzzles, help displaced animals, and uncover a story about friendship and finding home.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Capy Castaway**. This trainer enhances exploration and accessibility in Capy Castaway by adjusting movement, interaction, quest progression, collectibles, and character relationships. It is designed for the game's peaceful adventure structure and does not add combat mechanics.

**Target Audience:** Players who want a more relaxed exploration experience, faster travel, easier puzzle progression, convenient story experimentation, or help completing island activities and collectibles.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch the game first, load a save, and then activate the trainer. Use the movement multiplier for faster island traversal. Return the value to normal before entering scripted scenes or switching between characters if movement behaves unexpectedly.

### Tools & Inventory

Capy Castaway focuses on finding, carrying, and returning objects rather than traditional combat equipment. Use item and quest controls only when the relevant objective is active. Avoid changing item-related values during dialogue, cutscenes, or while Corvi is fetching an object.

### World & Environment

Use location and collectible options after the corresponding area has loaded. Teleport only to unlocked or recognized locations, and allow the game to finish loading before moving again. Save normally after completing activities, puzzles, or resident requests.

### Combat & Weapons

Capy Castaway has no conventional combat system. The trainer therefore provides no combat, weapon, damage, or health enhancements. Its gameplay options are focused on exploration, puzzles, character interactions, quests, and story outcomes.
